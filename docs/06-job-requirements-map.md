# 06 · Job Requirements Map

I built this project by reverse-engineering two entry-level GRC job descriptions. This page shows which requirement each part of the repository proves.

| Job requirement | Where it's demonstrated |
|---|---|
| "Conduct information security risk assessments" | Full assessment: [Methodology](02-methodology.md) + [Risk register](../risk-register/risk-register.md) |
| "Maintain the risk register and track remediation" | [Risk register](../risk-register/risk-register.md) with owners and dates; [Treatment plan](04-treatment-plan.md) |
| "Map controls to frameworks such as NIST CSF, HIPAA, and SOC 2" | Mapping row on every risk in the [register](../risk-register/risk-register.md) |
| "Knowledge of HIPAA Security Rule requirements" | [Scope & context](01-scope-and-context.md); HIPAA references throughout |
| "Support SOC 2 audit readiness and evidence collection" | SOC 2 mapping; evidence requirements in the [treatment plan](04-treatment-plan.md) |
| "Assess third-party and vendor risk" | R-04 (vendor without a BAA); third-party section of the [data flow](03-data-flow.md) |
| "Communicate risk to technical and non-technical stakeholders" | [Executive summary](05-executive-summary.md), written for leadership |
| "Understand data flows and where sensitive data is stored" | [Data flow diagram](03-data-flow.md) with trust boundaries |
| "Strong written documentation skills" | This entire repository |
| "Excel / spreadsheet proficiency" | [CSV risk register](../risk-register/risk-register.csv) |
